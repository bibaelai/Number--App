# Counter App

A small project I built while getting introduced to JavaScript.  
It’s simple, but it helped me practice connecting HTML, CSS, and JavaScript in a clean way.

##  Description

This app lets you:

- Increase the number  
- Decrease the number  
- Reset the number  

I wanted to challenge myself by **separating the code into three files** instead of writing everything in one HTML file:

- `main.html` → structure  
- `style.css` → styling  
- `index.js` → functionality  

This helped me learn how to organize my code better — a habit I want to develop early.

##  Built With

- HTML  
- CSS  
- JavaScript
